\# Dataset



The video files used for development and testing are not included in this repository because of their file size.



The project uses video data derived from the WildTrack dataset and additional crowd-analysis video samples.



\## WildTrack Dataset



WildTrack is a multi-camera dataset for pedestrian detection and tracking research.



Official dataset:



https://www.epfl.ch/labs/cvlab/data/data-wildtrack/
